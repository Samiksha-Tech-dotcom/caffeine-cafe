
# ☕ Caffeine — Café Ordering and Table Booking System

Caffeine is a full-stack café management web application designed to simplify online food ordering and streamline café operations. Customers can browse the menu, manage their cart and wishlist, place orders, view order history, and book tables online. The application also includes an admin panel to manage menu items, customer orders, and table reservations.

## ✨ Features

### 👤 Customer Features
- User registration and login
- Browse café menu items
- Add and manage items in the shopping cart
- Save favourite items to the wishlist
- Place orders and view order history
- Book tables online

### 🔐 Admin Features
- Add and manage menu items
- Manage customer orders
- Manage table reservations

## 🛠️ Technologies Used

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, MongoDB Atlas
- **Authentication:** JWT (JSON Web Tokens)
- **API:** REST APIs
- **Deployment:** Vercel (Frontend) and Render (Backend)

## 🎯 Project Objective

The objective of Caffeine is to provide a convenient digital platform for café customers and administrators by bringing online ordering, wishlist and cart management, table reservations, and café administration into one application.

## 👩‍💻 Project Overview

Caffeine is developed using the MERN stack and demonstrates full-stack web development, frontend-backend integration, database management, authentication, REST API development, and cloud deployment.
